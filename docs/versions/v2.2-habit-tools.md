# v2.2 — Habit Tools

**Status**: planned   **Goal**: give users reasons to return weekly, and each return produces a scoring signal.

## Features

### F2.1 Invoice generator with saved clients and history
- Saved client list, numbering, currency, tax lines, PDF export (existing PDF engine), invoice history.
- AC: invoice numbers are sequential per user; editing a saved client does not alter issued invoices.

### F2.2 VAT / tax threshold tracker
- User enters trailing revenue; app shows distance to registration/tax thresholds per jurisdiction and alerts when near.
- Threshold-hit is a high-intent scoring event and triggers a follow-up (F1.5).
- AC: threshold table has cited sources; alert fires once per crossing.

### F2.3 Company health score
- Percentage score from filled profile, current documents, deadlines on track, banking readiness; shows the single next step.
- AC: scoring rules documented and tested; next step changes as items complete.

### F2.4 Residency day counter
- Log travel days per country; warns approaching tax-residency/visa limits (rule table per country).
- AC: day counting handles year boundaries and overlapping entries; rules cite sources.

### F2.5 Document Locker v2 (paid / client tier)
- Unlimited docs, auto-read of expiry/number, bank-ready packs (multi-document share), offline copies, WhatsApp/email reminders, annual document review, "renew with us" requests, upsell by gap.
- AC: tier limits enforced server-side; a pack link exposes only the selected documents; renewal request creates a staff task with the quoted price.

## Dependencies
v2.1 locker, calendar, events and follow-up engine.

## Out of scope
Team access, receipts/expense capture, e-signature.
