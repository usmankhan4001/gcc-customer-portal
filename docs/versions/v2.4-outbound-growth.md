# v2.4 — Outbound & Growth

**Status**: planned   **Goal**: turn the user base and its signals into a qualified, consented outbound pipeline.

## Features

### F4.1 Audience segments and consent-aware export
- Saved segments by field/industry, country, revenue band, tools used, score stage; export or push to the outbound tool (CSV first).
- AC: export contains only contacts with a granted consent for the chosen channel; every export is logged (who, when, how many).

### F4.2 Attribution
- Record first and last source (campaign, referrer, tool) per user; show conversion by source.
- AC: attribution survives anonymous -> account signup (F1.1).

### F4.3 Revenue and funnel dashboard
- Visitors -> tool use -> saved -> installed -> lead -> client -> renewed; revenue by jurisdiction, package and source; 90-day renewal forecast.
- AC: numbers reconcile with `orders`/`renewals`; admin-only.

### F4.4 Partner and referral links
- Unique links for accountants/agents with attribution and commission tracking (may reuse `referrals`).
- AC: a referred signup is credited once; commission report exportable.

## Compliance notes
WhatsApp requires explicit opt-in and approved templates; honor unsubscribe within the same session; keep quiet hours per recipient timezone; document the lawful basis for outbound use of tool-user data.

## Dependencies
F0.6 consent/events, F1.3 scoring, F1.5 follow-up engine.

## Out of scope
Calls or LinkedIn automation, paid-ads sync, multilingual outbound.
