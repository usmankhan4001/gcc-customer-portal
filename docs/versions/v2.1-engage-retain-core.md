# v2.1 — Engage & Retain Core

**Status**: planned   **Goal**: the first full loop: use a tool, save it, get reminded, get scored, get followed up.

## Features

### F1.1 Light accounts (save results)
- Tools stay free; saving a result/company prompts WhatsApp OTP signup.
- AC: anonymous tool result can be attached to a new account after OTP; no data lost on signup.

### F1.2 Compliance calendar (hero retention tool)
- Per-company deadlines (annual return, VAT, licence renewal, ESR, etc.) by jurisdiction rules; editable.
- Reminders at configurable lead times via push, WhatsApp, email (respecting consent).
- AC: adding a company in a supported jurisdiction generates its deadlines; a reminder fires once per lead time; snooze/done works.

### F1.3 Lead scoring v1 (rules-based)
- Score from: tool depth/repeats, revenue band, jurisdiction, industry risk, app installed, push opt-in, saved items, threshold hits, recency.
- Outputs score, stage (cold/warm/hot/client/at-risk) and next action; visible in `/admin/leads`.
- AC: documented rule table with tests per rule; score recomputes on new events; stage change is logged.

### F1.4 Calculator and quiz verification
- Tests for tax calculator, VAT scorer, visa estimator, banking odds, QFZP, quiz; numbers checked against 2026 rules in `jurisdiction_tax_rules`.
- AC: table-driven tests with cited source for each rate/threshold; wrong inputs rejected with clear errors.

### F1.5 Follow-up automation
- Triggers: tool result, abandoned onboarding/checkout, deadline within N days, document expiring.
- Channels: WhatsApp (approved templates) and email; consent, quiet hours, frequency caps.
- AC: each trigger sends at most once per rule window; no send without consent; send log visible in admin.

### F1.6 Pre-filled quote link and consultation booking
- Tool result -> shareable quote link with jurisdiction/package pre-filled; booking slot request for consultation-led leads.
- AC: link opens the quote with the right defaults; booking creates a lead task and notifies staff.

### F1.7 Document Locker v1
- Free tier (about 10 docs). Camera scan with crop; manual or on-device read of expiry date; document types by jurisdiction pack.
- Expiry status (valid / expiring / expired) with reminders at 90/60/30/7 days; expiry also appears in the compliance calendar.
- Versions (replace on renewal keeps history); missing-documents checklist per goal ("bank-ready", "visa-ready").
- Secure share links with expiry, optional password, view-only, revoke; owner sees the access log.
- Biometric lock; delete-everything button.
- AC: each status transition and reminder is tested; shared link stops working after expiry/revoke; no raw R2 URL is ever returned; deletion removes R2 objects and rows.

## Dependencies
v2.0 (F0.3 auth, F0.4 push, F0.6 consent/events) must be done. F1.7 reminders share the engine built for F1.2.

## Out of scope
Auto-read in paid tier tuning, bank packs, paid tiers (v2.2).
