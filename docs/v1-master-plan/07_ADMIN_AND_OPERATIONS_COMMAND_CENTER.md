### 2. The 10-Stage Deal Pipeline (Kanban Board)

Every client engagement flows through 10 clear operational stages:

```
┌──────────────┬──────────────┬──────────────┬──────────────┬──────────────┐
│ 1. NEW LEAD  │ 2. CONTACTED │ 3. CONSULT   │ 4. PROPOSAL  │ 5. PROPOSAL  │
│              │              │    BOOKED    │    SENT      │    ACCEPTED  │
├──────────────┼──────────────┼──────────────┼──────────────┼──────────────┤
│ 6. PAYMENT   │ 7. OFFICIAL  │ 8. FILING IN │ 9. CORP BANK │ 10. ACTIVE / │
│    RECEIVED  │    PORTAL KYC│    PROGRESS  │    SETUP     │     COMPLETE │
└──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
```

* **Card Details**: Client Name, Target Jurisdiction, Selected Tier, Order Value ($), Days in Current Stage, Assigned Team Member.
* **SLA Alert Badges**:
  * 🟢 **Green**: Under 3 days in current stage.
  * 🟡 **Yellow**: 4–7 days in current stage.
  * 🔴 **Red**: > 7 days in current stage (requires immediate attention).

### 4. Customer 360 View (`/admin/clients/[id]`)

A unified screen summarizing everything about a client:
1. **Corporate Profile**: All companies owned, registration dates, trade license numbers, renewal dates.
2. **Corporate Kit Locker**: All issued government licenses and official corporate documents.
3. **Billing History**: Paid Stripe invoices, renewal receipts, pending balances.
4. **WhatsApp & Communication Timeline**: Complete log of all outbound automated WhatsApp alerts and inbound client replies.
5. **Private Internal Team Notes**: Add notes visible only to GCCStartup team members.
